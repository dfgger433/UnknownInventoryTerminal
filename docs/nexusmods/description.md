# Unknown Inventory Terminal

*A native Unity inventory terminal for Casualties: Unknown*

> 本文件是 [description.bbcode.txt](description.bbcode.txt) 的 Markdown 版本，内容一致，供仓库阅读或在支持 Markdown 的编辑器中使用。

## Overview

Unknown Inventory Terminal (UIT) opens one native Unity window in the middle of the screen and keeps every item interaction on the game's own logic. It reads the local character's real item instances, aggregates identical items by exact item ID, and never copies items, rewrites container hierarchies or adds network messages.

While the terminal is open, the vanilla radial inventory and container panels are not displayed.

## Features

- **Native window with a rebindable hotkey** — fixed in the centre of the screen and not draggable. It opens and closes with a hotkey (default **F7**) that is listed in the game's Input/Controls settings.
- **Searchable 6-column storage grid** — items are aggregated by exact item ID. Type to filter; right-click clears the search field and *Enter* leaves editing. Installing Just Unknown Characters adds pinyin matching to the same search.
- **Sorting, height and scrolling** — sort by name or quantity in ascending or descending order, switch between four terminal heights (*Small*, *Medium*, *Tall*, *Full height*), and scroll with the mouse wheel or the slider on the right.
- **Instance selection** — clicking an aggregated cell opens the concrete instances of that item. Actual items keep the vanilla *ContainerItem* / *InvButton* interaction, and their tooltips are generated by the vanilla game, so item data, CUCoreLib items and expandable descriptions stay intact. A group cell states that it shows one item's properties at a time.
- **Hands, main slots and equipment** — main hand (slot 0) and off hand (slot 1) are shown left to right, followed by the remaining slot indices. Those numbers are slot IDs, not new hotkeys. Equipment cells bind to the game's *wearSlotId*, empty slots included; wearables registered through CUCoreLib are appended automatically, filling the current row before adding full six-cell rows, and rows can be scrolled when they do not fit. Unusable slots show a red no-entry marker.
- **Drag to equip or store** — dropping on an equipment cell wears the item; dropping on a held or worn container cell stores it directly. Dropping on the storage grid follows the configured container placement rule: smallest remaining capacity, highest weight reduction, or manual container selection.
- **Precise fluid transfer** — drag a filled container onto another liquid container with free space and release. The dialog accepts an integer amount in millilitres or a horizontal slider; only *Transfer* pours, and *Cancel* leaves both items untouched. The limit is the smaller of the source contents and the target's remaining capacity.
- **Drag out to drop** — dragging an item out of the window and releasing it on the game view drops it on the ground. Releasing over the window keeps it.
- **Action bar** — drop an item on *Empty container* and hold the left mouse button to drain continuously; release to stop. Drop an item on *Use item* and click the left mouse button to use it. Moving the mouse away or right-clicking cancels a pending action.
- **Pinned bar** — drop an item on the lock button to pin it to the first row, and drop a pinned item on the same button to unlock it. Drag pinned items to reorder them; the row ignores search and sorting; with more than six pins the row scrolls or pages. Pinning survives closing and reopening the terminal for items the current character holds, and is never written to the save file.
- **In-terminal settings** — switch the terminal language (English / Simplified Chinese), choose the container placement rule, and toggle *Keep item after action*. The hotkey lives in the game's Input/Controls settings.

## Requirements

- **Required:** Casualties: Unknown (Steam)
- **Required:** BepInEx 5.4.x (x64) — local development used 5.4.23.5
- **Required:** CUCoreLib 1.1+ — settings and keybind registration
- **Optional:** Casualties Together — multiplayer compatibility
- **Optional:** Just Unknown Characters — pinyin search

The plugin targets .NET Standard 2.1 and is loaded by BepInEx 5. It does not require Minecraft, Applied Energistics 2 or NeoForge at runtime.

## Installation

1. Install BepInEx 5.4.x (x64) into the game folder and run the game once so BepInEx generates its folders.
2. Install CUCoreLib so that `BepInEx/plugins/CUCoreLib.dll` exists.
3. Unpack the downloaded archive and copy the `UnknownInventoryTerminal` folder into `BepInEx/plugins/`. The result should be `BepInEx/plugins/UnknownInventoryTerminal/UnknownInventoryTerminal.dll`.
4. Launch the game and press **F7**. The hotkey can be changed in the game's Input/Controls settings.

The installer copies only this mod's plugin DLLs, language files, GUI screen description, textures, the licence text and the asset notice into its own folder. It does not modify game DLLs, Together or save files.

## Uninstallation

Close the game, then delete the `BepInEx/plugins/UnknownInventoryTerminal` folder. The mod writes nothing to save files; a leftover configuration entry in the BepInEx config file can be removed as well.

## Multiplayer

The terminal is client-side. A client using its own backpack items does not require the host to install UIT, as long as the host runs a compatible Together version. Draining containers reuses Together's existing synchronisation messages; if a session cannot synchronise safely, the drain is refused and no liquid is changed. UIT itself adds no network messages — item transfers still go through the game's own item interaction paths.

## Verification status

Automated tests cover inventory projection, search, the six-column layout and equipment row expansion, as well as the screen JSON, atlas cropping and asset bounds. In-game Unity rendering, vanilla item interaction and the Together host/client chain still need acceptance testing on the target game version. The mod is in early development, so features and interfaces may still change.

## Frequently asked questions

**The hotkey does nothing.** Check the game's Input/Controls settings — the terminal key is listed there and can be rebound. Also confirm CUCoreLib is installed.

**Why is the vanilla inventory gone when the terminal is open?** By design: the terminal replaces the browsing view, and the vanilla radial inventory and container panels are hidden while it is shown.

**Do I need Together?** No for single-player. Together is only needed for multiplayer compatibility, and the host needs a compatible Together version rather than UIT.

**Does the mod touch my save?** No. Pin state is kept in memory for the current character and is not saved; settings live in the BepInEx config file.

**Pinyin search does not work.** It requires Just Unknown Characters to be installed. Without it, the normal text search still works.

**Why do I see only one item's properties on a group cell?** Group cells show one instance at a time by design; click the cell to browse every instance of that item.

## 简体中文

### 简介

Unknown Inventory Terminal（UIT）在屏幕中央打开一个原生 Unity 窗口，所有物品交互仍走游戏自身的逻辑。终端只读取本地玩家的真实物品实例，按精确物品 ID 聚合同类物品，不复制物品、不修改容器层级，也不新增任何网络消息。

终端打开期间，原版径向物品栏和容器面板不显示。

### 功能

- **原生窗口，快捷键可改绑** — 窗口固定在屏幕中央，不可拖动；默认按 **F7** 打开或关闭，按键列在游戏的「设置 → 输入/控制」中。
- **六列可搜索仓储网格** — 按精确物品 ID 聚合；输入文字即可过滤，右键清空搜索框，*Enter* 退出编辑。安装 Just Unknown Characters 后，同一个搜索框会接入拼音匹配。
- **排序、高度与滚动** — 可按名称或数量升/降序排列，在 *短*、*中等*、*长*、*最长* 四档终端高度间切换，并用鼠标滚轮或右侧滑块逐行滚动。
- **实例选择** — 点击聚合格进入该物品的具体实例页；实际物品继续使用原版 `ContainerItem` / `InvButton` 交互，悬浮说明由原版生成，物品数据、CUCoreLib 物品与展开描述都保持原样。聚合格会标明当前只展示一件物品的属性。
- **双手、主槽位与装备** — 主手（槽位 0）与副手（槽位 1）从左到右排列，随后是其余槽位索引；这些数字是槽号，不是新增快捷键。装备格绑定游戏的 `wearSlotId`，空槽也显示；通过 CUCoreLib 注册的可穿戴物品会自动补进装备栏，先填满本行再增加完整的六格行，放不下时可在装备栏逐行滚动。不可用槽位显示红色禁止标识。
- **拖动穿戴与存放** — 拖到装备格可穿戴，拖到手持或已穿戴的容器格可直接存入。拖到仓储网格时按设置的容器放置规则处理：优先剩余容量最小的容器、优先减重最多的容器，或手动选择容器。
- **液体精确转移** — 把装有液体的容器拖到另一个有空间的液体容器上再松开。弹窗可输入整数毫升或拖动横向滑块；只有点「转移」才会倒入，点「取消」两件物品都不变。上限取来源存量与目标剩余容量中较小的一项。
- **拖出丢弃** — 把物品拖出窗口并在游戏画面内松开，即可丢到地上；拖回窗口内松开则不会丢弃。
- **快捷动作栏** — 把容器拖到「倒空容器」上按住鼠标左键可持续倒液，松开即停；把物品拖到「使用物品」上单击左键即可使用。移开鼠标或右键可取消等待中的操作。
- **固定栏** — 把物品拖到锁定按钮上松开即可固定到仓储首行，把已固定的物品拖到同一按钮即可解锁。拖动固定栏中的物品可调整顺序；固定栏不受搜索或排序影响；超过六件时可滚动或点击翻页。关闭再打开终端仍保留当前角色持有物品的固定状态，且不写入存档。
- **终端内设置** — 可切换终端语言（English / 简体中文）、选择容器放置规则、开关「动作后保留物品」。快捷键位于游戏的「设置 → 输入/控制」。

### 联机

终端是客户端模组。客机使用自己的背包物品时，主机无需安装 UIT，但需运行兼容的 Together。倒液复用 Together 既有的同步消息；若当前会话无法安全同步，倒液会被拒绝且液体不变。UIT 本身不新增网络消息，物品转移仍通过游戏自身的交互路径完成。

### 常见问题

**按快捷键没有反应。** 先看游戏的「输入/控制」，终端快捷键在那里列出并可改绑；同时确认已安装 CUCoreLib。

**为什么终端打开后原版物品栏不见了？** 这是设计行为：终端接管了浏览界面，显示期间原版径向物品栏和容器面板不显示。

**必须安装 Together 吗？** 单机不需要。Together 只用于联机兼容，且主机需要兼容版本的 Together，而不是 UIT。

**会改动存档吗？** 不会。固定状态只对当前角色保存在内存中，不写入存档；设置保存在 BepInEx 配置文件中。

**拼音搜索不可用。** 拼音匹配需要安装 Just Unknown Characters；未安装时普通文本搜索仍然可用。

**为什么聚合格只显示一件物品的属性？** 聚合格按设计一次展示一件实例；点击即可逐件查看该物品的所有实例。
