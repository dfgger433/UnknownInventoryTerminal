# Cold Inventory / 冷库存

这套视觉以“被精确整理的寒冷秩序”为核心：像一台在暗处等待操作的原生终端，安静、可靠、没有未来主义的浮夸。界面自身的像素格与精确边界承担叙事；背景只提供深度与留白，不模拟游戏场景，也不假装实机摄影。

空间由明晰的矩形窗口、网格和分栏构成。每个格位保留可呼吸的间距，边缘层层收束，像经过长期使用的精密仪器。视觉重心应落在搜索框、六列储物格及下方装备区域之间，靠比例与秩序表达功能，而非大量注释。

色彩限于煤灰、冷灰蓝、浅雾白与一点冰蓝。材质感来自细微颗粒、低反差光晕和克制的分层阴影；不可把 UI 纹理磨平，也不可用强烈渐变掩盖原始像素。所有贴图都按其本来比例细致裁切，只有为清楚展示而放大时才使用整数倍最近邻缩放。

头图以字形与界面片段形成横向张力，主图则让完整界面安静地居中。两者以尺度和留白区分职责，但共享相同的明暗、线条与间距节奏。稀少的文字只做识别与说明，不添加未经验证的功能承诺；示意图须清楚表明它是界面预览而非实机截图。

最终执行应像经过反复校准的产品图册：边缘锐利、对齐一致、层次耐看。每个裁切、间距、色阶和字距都须经细致推敲，呈现出长时间打磨与顶级工艺的结果；宁可删去一项装饰，也不让任何多余元素打断视觉秩序。
